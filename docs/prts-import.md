# PRTS 网站资料导入

本项目提供限定文章清单的低速导入脚本，当前读取 https://prts.wiki 的公开文章正文，默认不递归抓取整站。

## 本次收录范围

- 新人入门、作战机制、伤害分类、技能。
- 阿米娅、芬、克洛丝、桃金娘：特性、获取、属性、天赋、潜能、技能、后勤、培养材料与模组等可提取章节；不收录档案故事和语音。

页面按站内章节拆分为 `knowledge/prts/页面名称/*.md`。首次运行后，当前应用里点击“知识库 → 重建索引”，或者重启后端即可生效。已有手工资料和演示资料不会被覆盖。

## 运行与扩充

项目根目录执行：

```powershell
# 第一次启动脚本已安装 beautifulsoup4；旧环境可先运行 start.bat --install-only
.\.venv\Scripts\python.exe scripts/import_prts.py

# 更新脚本之前管理的页面，保护有手工修改的文件
.\.venv\Scripts\python.exe scripts/import_prts.py --refresh

# 从存档 HTML 重新整理，不再次访问网站
.\.venv\Scripts\python.exe scripts/import_prts.py --from-cache
```

扩充 `scripts/prts-pages.json`，添加条目即可：

```json
{"title": "你想收录的PRTS文章标题", "category": "干员", "tags": ["名称", "昵称"]}
```

category 使用现有六种分类。当前对“干员”只提取上述战斗相关标题；其他分类按全部正文章节提取。动态页面、复杂表格和新页面模板可能需要进一步调整，导入后应检查原文和检索效果。

脚本遵循抓取时取得的 robots.txt，使用明确 User-Agent，文章请求间隔至少 3 秒；403/429 或网络连接异常时停止后续抓取。不会访问登录页、特殊页或下载图片、视频。已导入页面默认跳过，使用 `--refresh` 才重新请求；不会无限自动重试。

## 抽取与来源

每份 Markdown 带标准知识库头部，同时增加：

| 字段 | 用途 |
| --- | --- |
| revision_id | 页面修订编号 |
| updated | 源页面最后编辑日期，缺失时明确标注未知 |
| fetched_at | 采集时间，UTC+8；不代表游戏版本 |
| license / license_url | 页面许可及链接 |
| original_title | 原文标题 |
| attribution | 贡献者署名说明 |
| extraction_note | 对原文做了哪些整理和未提取什么 |

后端会将这些字段保留到 Document 元数据中。来源 URL 带章节锚点，方便从回答引用找到对应原文。`knowledge/prts/import-report.json` 记录页面清单、修订号、生成文件 SHA-256 和失败原因；`.runtime/prts/` 保存抓取时的原始 HTML 与 robots.txt，便于复查，但不参与检索。

正文处理包括导航清理、去除重复手机版表格、去除隐藏算法/弹出提示（保留属性表中的信赖和潜能条件）、数学公式提取、表格行转为带列名的文本。技能表每行重复技能名、触发/回复类型与可识别的解锁条件；Rank Ⅰ/Ⅱ/Ⅲ 增加“专精一/二/三”文字，方便中文检索。没有使用模型补写或推断攻略。

图片、地图坐标、攻击范围图、视频、交互计算器没有转录。某些表格结构与关联条件依然可能需要人工检查；数值问题应核对原页面，并明确技能等级、潜能、模组和精英化条件。

## 内容许可

采集页面的 HTML `rel="license"` 标注为 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)。导入资料署名为 **PRTS Wiki 各页面贡献者**，每份文件保留原始页面链接；原文作者列表与编辑历史在原站查看。正文经过格式清理和章节拆分，改动记录见 extraction_note。

本批整理资料沿用该许可：署名、非商业性使用、相同方式共享。该许可针对资料，并不把本项目的其他代码一并改为此许可。游戏原始文本、图像与其他素材可能另有权利归属，以原站声明和原权利人为准。本工具没有下载媒体素材。

## 刷新注意事项

脚本通过 SHA-256 检查已管理文件是否被手工改动，遇到冲突会保留本地文件并报告。源站章节改名或删除时，旧文件不会被自动删除，而是列在报告的 `stale_files` 中；请检查后自行处理，避免旧资料长期参与检索。

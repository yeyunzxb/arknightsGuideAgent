# PRTS · 新人入门 · 准备攻关 / 情报、分析、作战、应对

如需了解

所有游戏内提示

，您也可以查阅

贴士一览

页面。

通过长按地形或点击物体来了解游戏机制。

进入关卡前，画面右侧会显示关卡详情，包括：

关卡情报 ，它通常会提供/透露关卡的作战要点以及关卡内的机制，请务必仔细阅读。

关卡地图 ，可用于初步规划布局。

敌人情报 ，查看本关卡出现的敌人及其能力。

首次遇到的关卡，其敌人情报都是不明的 ，你只能知道大致有多少种敌人会出现在本关卡中，以及通过过滤器大致了解它们的部分属性。 在攻关过程中出现在地图上的敌人将在当次行动后进入敌人情报中供你研究。

在行动中，你也可以注意以下几个帮助你了解关卡的方法：

对于从未见过的敌人，以及部分地图中特殊强化的部分敌人，画面右上角会弹出情报提示框，必要时请暂停后仔细阅读。 也有一些只是纯剧情上的描述，这就看鹰角是怎么想的了……

如果这张地图中存在一些全新的地形，你也可以在任何时候（包括暂停状态）按住该地形块，在画面右上角查看这个地形的描述和作用。 对于新出现的物体（例如装置），你也可以通过在地图中点按来查看详细情报。 永远记住随便点点是不亏的。

一般的，结束一次行动后会获得关卡评价：

歼灭关卡内所有目标敌人且未损失目标生命值即获得 3星评价 （或称完美通关），在突袭模式则改为 4星评价 （或更高的评价）； 获取源石必须至少达成3星评价。

如果未能满足3星评价，但目标生命值剩余至少1点，则获得 2星评价 ，依旧视为过关；

目标生命值降至0，则 行动失败 。

在二测时期是存在1星评价的，额外的条件为“我方干员被击倒扣1星”，但公测删除了这个条件，所以现在最低通关评价必定是2星了。

有了情报与地图信息，你便可以进行分析，更加针对性地编入合适的干员，比如：

关卡里根本 没有空中单位 → 可以不需要那些优先对空的狙击干员（除非你需要能天使的过载模式那样的技能扫荡地面）

关卡里的敌人是 高质量和重量、且以你干员目前的物理作战能力无法破甲的“盾哥” → 也许使用术师干员会更有效

关卡里的敌人是 人均法抗A的萨卡兹 → 也许使用狙击与近卫造成的伤害会更高

若有 双抗均高或带有物法减伤 的敌人出现 → 利用敌人特性和地图机制（如果有），并根据情况选择带有真伤、元素损伤、辅助性质的干员（当然也可以用正常输出硬灌死对面）。

关卡部署费用 自然回复速度降低或不回复 ，无法正常展开阵型 → 尝试牺牲一些其他位置多带先锋，或者换用执旗手、情报官等高效率回费干员，产出大量费用并用于队伍展开

自己的重装干员 完全拦不住某个敌人 → 放弃阻挡，使用高台干员用控制与输出无阻挡地灌死对手

地图里有 地穴 ，或者因为是高楼而边缘有“地穴” → 采用可以位移敌人的干员（例如推击手和钩索师），让敌人尝尝高空坠崖的感觉

有些地图 没有可以远程攻击的敌人 → 可以不用过于在意部署顺序

关卡攻关的基本操作（部署方向与顺序、撤退、技能使用）都已经在新手教程关（包括游戏一开始的引导关卡和各个TR关卡）中传授于你。比如：

干员需要一定的部署费用才能部署，部署费用可以通过时间自行恢复，速度为1倍速下每秒1点。 大部分情况你需要 先锋干员 来帮你在前期快速回复部署费用用于展开你的阵型，同时应对关卡前期的敌人。 当然这不是绝对的，因为总会有先锋接不住的敌人，或者根本没有先锋下场的地面。如果遇到这种情况（指你确实遇到了）， 请灵活应对 。

随时留意进入地图时的小Tip。要说其中最精髓的一句，那么这句Tip应该是： 干员合理的入场顺序以及正确的技能释放时机能左右战场局面 你需要 牢记所有教程关所教给你的知识 ，或者 被一些必须牢记这些知识方可进行的关卡打爆，然后牢记所有教程关所教给你的知识 。 你也可以参阅 游戏数据基础 或 作战机制 页面，获得对游戏部分机制的深入理解。

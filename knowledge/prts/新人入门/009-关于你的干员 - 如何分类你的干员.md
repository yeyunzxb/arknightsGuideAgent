# PRTS · 新人入门 · 关于你的干员 / 如何分类你的干员

在罗德岛系统中，干员们被划分成8种“职业”。即使是同一种职业的干员，也有 不同的特性和功能 。因此即使是同一职业的干员，在过关时也不能互相随意替换。

目前官方对这些干员使用了“分支”系统来进行划分，但也存在一些较失偏颇的情况，我们会在下方单独拎出来讲。

为简明起见，下表并没有完全列出该分支下的全部干员。

(6) —— 对部署有更佳效果的职业

干员部署费用普遍较低或适中，能产出额外部署费用的职业。

通常用于用于关卡前期展开阵型、补给部署费用。

[图示：尖兵] 尖兵：可以阻挡2个敌人，通过技能回复费用的分支。 其中有些偏向输出特化，有些偏向防御特化，使用时需要注意。

[图示：尖兵] 尖兵：输出特化 防御特化 均衡型 嵯峨 德克萨斯 清道夫 香草 焰尾 凛冬 讯使 芬 推进之王

[图示：冲锋手] 冲锋手：可以阻挡1个敌人，通过击杀敌人回复费用的分支，其在撤退时还会返还等同首次部署消耗的费用。 一般攻击力较高，防御力较低。

[图示：冲锋手] 冲锋手：风笛 苇草 红豆 翎羽

[图示：执旗手] 执旗手：可以阻挡1个敌人，开启技能时可以回复费用但阻挡数会变为0的分支。 作为交换，其费用获取效率在先锋职业中处于高位，并且在此之外还具有一定辅助能力。

[图示：执旗手] 执旗手：琴柳 极境 桃金娘

[图示：战术家] 战术家：部署在高台位，并可使用战术点支援作战的分支，并通过技能回复费用。 战术点是可部署于战术家攻击范围内的召唤物，拥有被击倒后重生的特性，与战术家的技能配合可以提供输出、扛伤、支援等各种效果。

[图示：战术家] 战术家：伺夜 夜半 豆苗

[图示：情报官] 情报官：可以阻挡1个敌人，进行远程攻击，开启技能时通过攻击到敌人来回复费用的分支。 该分支也具有较短的再部署时间，适合游走攻击敌人以灵活获取部署费用。

[图示：情报官] 情报官：伊内丝 晓歌 冬时

[图示：策士] 策士：可以阻挡2个敌人，通过技能回复费用的分支。 与【尖兵】相比，该分支的干员更注重其对位于待部署区的干员的支援能力。

[图示：策士] 策士：凛御银灰 松桐

(14) —— 近战攻击为主的输出职业

本游戏任职占比最高的职业。

干员部署费用适中或中高，字面意义上的以近战攻击为主来提供输出的职业，是地面输出的主要来源。

[图示：无畏者] 无畏者：阻挡并攻击1个敌人的分支。攻击力较高，血量较高，但防御力较低。 适合借助高火力与高血量优势进行对单输出。

[图示：无畏者] 无畏者：斯卡蒂 芙兰卡 缠丸 玫兰莎

[图示：强攻手] 强攻手：可以阻挡2-3个敌人，并且可以同时攻击等于阻挡数的敌人的分支。 适合借助打多优势阻挡并清剿较多的敌人。

[图示：强攻手] 强攻手：煌 幽灵鲨 艾丝黛尔 泡普卡

[图示：领主] 领主：通常可阻挡2个敌人，可以远程攻击的近卫分支，且可攻击空中单位。 拥有较长的攻击范围，但在进行远程攻击时攻击力会降至80％。适合借助射程优势先发制人。

[图示：领主] 领主：银灰 拉普兰德 霜叶 月见夜

[图示：术战者] 术战者：通常可阻挡1个敌人，普通攻击即可造成法术伤害的分支。 拥有较为稀少的地面法伤，可作为法术输出的补充位。

[图示：术战者] 术战者：史尔特尔 星极 慕斯

[图示：剑豪] 剑豪：通常可阻挡2个敌人，普通攻击连续造成2次伤害的分支。 提供高攻击次数的同时，该分支大多数技能为攻击回复技能，以此执行爆发性输出。

[图示：剑豪] 剑豪：陈 柏喙 刻刀

[图示：武者] 武者：通常可阻挡1个敌人，不能被治疗 ，通过攻击到敌人回复血量的分支。 一般拥有随着血量降低而提升某类属性的坚忍天赋，可用于适时迎接中高威胁敌人。

[图示：武者] 武者：赫拉格 赤冬 宴

[图示：斗士] 斗士：通常可阻挡1个敌人，具有高攻击速度（短攻击间隔）的分支。 其部署费用较低，依靠高攻击频率对敌人造成打击。

[图示：斗士] 斗士：山 燧石 猎蜂

[图示：教官] 教官：通常可阻挡2个敌人，攻击力较低，但具有前方3格的攻击距离，且攻击自身未阻挡的敌人时攻击力提升至120%。 具有对其他干员的支援效果。

[图示：教官] 教官：帕拉斯 诗怀雅 杜宾

[图示：收割者] 收割者：通常可阻挡2个敌人，可以同时攻击范围内的所有敌人，但不能被治疗，通过攻击到敌人回复血量的分支。 整体类似【强攻手】与【武者】的组合版，其中“攻击敌人回复生命”时，这次攻击到的每个敌人都可以回复一定量生命，但上限数等同于阻挡数，适合【武者】单人无法处理的敌人较多的情况。

[图示：收割者] 收割者：圣约送葬人 羽毛笔 休谟斯

[图示：解放者] 解放者：通常可阻挡2~3个敌人，但通常不攻击也不会阻挡敌人，并在非技能期间攻击力逐渐提升，技能结束后重置攻击力的分支。 适合长时间蓄力后短期爆发的战斗类型。

[图示：解放者] 解放者：玛恩纳 龙舌兰 骋风

[图示：重剑手] 重剑手：通常可阻挡2个敌人，并且可以同时攻击等于阻挡数的敌人的分支。 相较于【强攻手】，牺牲了防御性能（双抗均为0）换来超高的攻击力与生命值（均高于无畏者）。 适合应对部分高压场合，但需要必需的医疗支援。

[图示：重剑手] 重剑手：赫德雷 铎铃 石英

[图示：撼地者] 撼地者：通常可阻挡2个敌人，攻击使目标周围的其他敌人受到相当于攻击力50%的群体物理伤害的分支。 攻击力仅次于重剑手，但部署费用略高于无畏者，适合相较于【收割者】更需要站场的场合。

[图示：撼地者] 撼地者：怒潮凛冬 奥达

[图示：本源近卫] 本源近卫：通常可阻挡2个敌人，通过技能或者天赋效果可以造成元素损伤或元素伤害的分支（参见 元素 ）。 根据所需元素损伤类型不同，该分支下的干员被进一步的细分，使用时需要注意。 该职业分支的干员通常需要与其他可对敌方造成元素损伤的干员进行配合才可让其主要元素伤害输出技能发挥全部作用。

[图示：本源近卫] 本源近卫：神经 侵蚀 灼燃 凋亡 聆音 克莱门莎 塔露拉

[图示：佣兵] 佣兵：通常可阻挡2个敌人。其需要消耗费用开启技能，但同时也能消耗费用进行【装备应变】从而触发额外的技能效果。

[图示：佣兵] 佣兵：哈蒂娅

(9) —— 擅长远程物理攻击的输出职业

在高台上造成物理伤害的职业。

可进行大范围的远程射击，以攻击空中单位为主，是高台物理输出来源。

[图示：速射手] 速射手：优先攻击空中单位的分支。 每次只能攻击1个敌人，但攻速较快，能够快速有效解决大部分空中敌人。

[图示：速射手] 速射手：能天使 蓝毒 流星 克洛丝

[图示：炮手] 炮手：攻击可以造成溅射群体伤害的分支。 拥有比速射手更大的攻击范围，但攻速较慢，部署费用高，适合作为后排远程火力支援。

[图示：炮手] 炮手：菲亚梅塔 陨星 白雪 空爆

[图示：散射手] 散射手：以狭小的攻击范围为代价，同时攻击范围内所有敌人的分支。对自身前面一排范围内敌人攻击力提高至150%。 攻速较慢，伤害高，部署费用高于炮手，适宜前排压制。

[图示：散射手] 散射手：假日威龙陈 送葬人 松果

[图示：重射手] 重射手：以较小的攻击范围为代价，换取超高物理输出的分支。 每次只能攻击1个敌人，攻速较慢，适合作为对单体目标的决战型输出。

[图示：重射手] 重射手：黑 普罗旺斯 酸糖

[图示：神射手] 神射手：攻击范围非常大，攻击力较高，但优先攻击防御最低的敌人的分支。 每次只能攻击1个敌人，攻速较慢，部署费用高于重射手，适宜远距离清剿目标单位，但需要友方支援创造狙击条件。

[图示：神射手] 神射手：远牙 守林人 安比尔

[图示：攻城手] 攻城手：攻击范围非常大，攻击力较高，但优先攻击重量最重的敌人，且无法攻击自己前面一排的分支。 每次只能攻击1个敌人，攻速较慢，部署费用高于神射手，适宜凭借射程优势和对重特性远距离处理敌人（含高威胁敌人）。

[图示：攻城手] 攻城手：早露 熔泉 铅踝

[图示：投掷手] 投掷手：攻击范围非常大，但只攻击地面单位，每次攻击会额外附带余震（伤害降低的群体溅射伤害）的分支。 攻速较慢，部署费用略高于攻城手，但低于炮手。其特性决定其可作为高台位上的对地物理输出出战。

[图示：投掷手] 投掷手：维什戴尔 迷迭香 承曦格雷伊

[图示：猎手] 猎手：攻击范围类似【近卫 - 领主】，每次攻击需要消耗“子弹”的分支。 攻速较慢，且子弹为空时需要装填子弹才可继续攻击；拥有子弹时攻击力提升，伤害较高，部署费用略低于攻城手。其特性决定其需要友方支援创造输出条件后执行清剿。

[图示：猎手] 猎手：莱伊 冰酿

[图示：回环射手] 回环射手：攻击范围与【速射手】相近，攻击改为投出回旋投射物的分支。 投射物需要时间回收，且持有回旋投射物时才能进行攻击，使得实际攻速与敌方位置强相关，攻速加成收益极小，攻击力略低于散射手。部署费用略高于速射手，低于重射手。 其特性使得其可对自身周围的敌人造成可观的伤害。

[图示：回环射手] 回环射手：娜仁图亚 水灯心 跃跃

[图示：裂空炮手] 裂空炮手：常态 起飞 并仅攻击空中敌人，技能开启后降落并造成群体物理伤害的分支。 其特性类似【炮手】，但因起飞特性具有阻挡空中单位的效果。

[图示：裂空炮手] 裂空炮手：天空盒

(9) —— 擅长远程法术攻击的输出职业

能够造成远程法术伤害的职业。

可进行较小范围的远程射击，是高台（乃至全局的）法术输出来源。

[图示：中坚术师] 中坚术师：每次攻击1个敌人的分支。 单体攻击能力较强，可作为常规的法术输出位。

[图示：中坚术师] 中坚术师：艾雅法拉 阿米娅 夜烟 史都华德

[图示：驭械术师] 驭械术师：类似【中坚术师】，但额外拥有浮游单元的分支。 攻击力较低，但可以与浮游单元协同攻击，且自身与浮游单元攻击同一敌人时伤害提升（最高110%攻击力）。 技能通常能够释放浮游单元锁定敌人，被锁定的敌人在攻击范围外仍会受到浮游单位的追击，适宜需要追击敌人的场合。

[图示：驭械术师] 驭械术师：澄闪 耶拉 卡达

[图示：扩散术师] 扩散术师：攻击可以造成溅射群体伤害的分支。 攻击速度较慢，部署费用高，攻击范围较小，适合面对大量敌人的场合。

[图示：扩散术师] 扩散术师：莫斯提马 天火 远山 炎熔

[图示：轰击术师] 轰击术师：攻击范围为距离极远的一条直线的分支。 每次攻击可以对范围里的全部敌人造成伤害，攻击速度较慢，部署费用高。在某些部署位置下可以作为奇兵出击。

[图示：轰击术师] 轰击术师：伊芙利特 蚀清 协律

[图示：阵法术师] 阵法术师：技能未开启时不攻击但双抗提升的分支。 技能开启后对自身周围的全部敌人造成伤害，因此需要规划技能的开启时机，也可以作为“高台重装”使用。

[图示：阵法术师] 阵法术师：卡涅利安 蜜蜡 薄绿

[图示：链术师] 链术师：攻击可以在多个敌人间跳跃并造成短暂停顿的分支。 攻击速度较慢，伤害低，部署费用高，适合需要同时兼顾牵制的场合。

[图示：链术师] 链术师：异客 惊蛰 布丁

[图示：秘术师] 秘术师：无攻击目标时可以储存攻击能量，并在下次攻击时一起发射的分支。 攻击速度非常慢，但攻击非常高，适合作为对单体目标的决战型输出。

[图示：秘术师] 秘术师：黑键 爱丽丝 深靛

[图示：本源术师] 本源术师：攻击范围与【中坚术师】一致，但天赋或技能效果可以对敌方造成元素损伤或元素伤害的分支（参见 元素 ）。 根据所需元素损伤类型不同，该分支下的干员被进一步的细分，使用时需要注意。 该职业分支的干员通常需要与其他可对敌方造成元素损伤的干员进行配合才可让其主要元素伤害输出技能发挥全部作用。

[图示：本源术师] 本源术师：神经 侵蚀 灼燃 凋亡 真言 Miss.Christine 烛煌 温米 妮芙 折光

[图示：塑灵术师] 塑灵术师：攻击范围与【中坚术师】一致，但可以通过击倒敌人生成召唤物的分支。 召唤物不占用部署数量，且自身也可以攻击到自身召唤物阻挡的敌人。其生成条件，功能与作用随相应干员的天赋或技能效果而不同，在清理低威胁敌人的场合有着奇效。

[图示：塑灵术师] 塑灵术师：死芒 特克诺

(7) —— 提供治疗回复生命的职业

在高台上恢复我方单位生命的职业，俗称“奶妈”，是队伍中保全我方单位的“救助队”。

通常攻击力就是治疗量，俗称“奶量”。

[图示：医师] 医师：每次攻击可治疗1名我方单位的分支。治疗量较高。

[图示：医师] 医师：医师 自称医师 闪灵 赫默 苏苏洛 安赛尔 凯尔希

[图示：群愈师] 群愈师：每次攻击可同时治疗3名我方单位的分支。单体治疗量较低。

[图示：群愈师] 群愈师：夜莺 白面鸮 调香师

[图示：疗养师] 疗养师：拥有极大攻击范围、通过天赋或技能为我方干员提供 抵抗 效果、降低部分负面效果持续时间的分支。

[图示：疗养师] 疗养师：流明 絮雨 清流

[图示：行医] 行医：拥有极大攻击范围、可以治疗 元素损伤 的分支。 即使目标的生命值为满也能治疗元素损伤。 和【疗养师】的攻击范围有一点差别，使用时需要注意。

[图示：行医] 行医：纯烬艾雅法拉 桑葚 褐果

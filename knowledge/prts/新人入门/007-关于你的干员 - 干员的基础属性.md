# PRTS · 新人入门 · 关于你的干员 / 干员的基础属性

在干员详情页可以查阅的干员面板，点击后就能展开每个图标所代表的意义。

一个干员拥有最基础的八项属性值。通过这些属性值可以了解这个干员的基础性能。

游戏数据基础 中对属性含义和计算方式有更详细的描述，感兴趣可以查阅。

生命上限

决定干员单次能够承受的伤害上限。

与之关联的局内属性为（当前）生命值，它代表干员在当前时刻能够承受的伤害上限。

一般情况下，当干员生命值降低为0时，该干员就会被强制撤退，从场上消失并进入再部署冷却阶段。

但有少数时候，可以看见生命值为0的单位仍然存活，这是因为生命值和伤害值保留了小数部分的计算，当单位实际生命值在0~0.5时，由于四舍五入，在面板上显示生命值为0。

生命上限出现变动时，生命值会等比变动以保持生命比例不变。

攻击

干员单次攻击能够造成的伤害量。

在没有特别标注的情况下，默认代表这个干员进行的是 物理攻击 ，除非在其他地方特别标注有伤害类型字样，比如 “攻击造成法术伤害” （一般是写在特性里，也有技能描述改变伤害类型的等等情况）。

但攻击值不代表最终能够造成的伤害，伤害量会将目标的 防御力 和 法术抗性 计入其中。当物理攻击力小于目标防御力，或者目标的法术抗性大于95时，只会造成很低的伤害（俗称“抛光”）。

具体计算方式是取【最终伤害】与【攻击力的 5% 】两者中的 最大值 （敌我均是如此，即5%保底伤害）。

特别的，干员 石棉 、干员 月禾 等能够减少伤害的效果会在伤害量计算完毕后再降低，因此可能出现受到的实际伤害比5%敌方攻击力还要少的情况。

对于 医疗干员 等会对我方单位进行治疗的单位，这个值即等同于治疗量。

防御

干员承受 单次物理伤害 时能够减免的数值。

物理伤害的计算使用加算计算法则：伤害 = 攻击力 - 防御力 。

例： 一个防御为500的单位受到了一次750的物理攻击，那么这个单位实际受到的伤害为 750 - 500 = 250 。

法术抗性

干员承受 法术伤害 时，能够减免的百分比。

最大值为100，法术抗性为25即基本等同于所受法术伤害减伤25%。

法术伤害的计算使用乘算计算法则：伤害 = 攻击力 × ( 1 - 法术抗性% ) 。

例： 一个法抗为10的单位受到了一次200的法术攻击，那么这个单位实际受到的伤害为 200 × ( 1 - 10% ) = 180 。

再部署

干员离开战场后能够再次允许部署到战场上所需要时间的大致区间。

再部署时间的属性仅有四档： 快： 16秒或18秒，以处决者分支为主。 中等： 少数为22秒或25秒，多数为60秒；部分70秒再部署时间的干员的潜能提升会使再部署时间从70秒先降低4秒再降低6秒，降低10秒时从“慢”变为“中等”。 慢： 70秒或66秒，少数为80秒或62秒；绝大部分干员均为70秒的此档位。 非常慢： 200秒，以1星干员为主。

部署费用

干员 第一次进入战场 需要消耗的部署费用。

在每次作战中，第一次撤退后部署费用变为该数值的 1.5倍（向下取整） ，第二次撤退及以后再部署变为该数值的 2倍 。

通常情况下，每次手动撤退（或者说主动撤退）会返还该干员 当次部署所消耗费用的一半（向下取整） 。

除了极罕见的情况，部署干员需要的费用不会超过99，即使该干员理论消耗的费用已经超过99（部分突袭条件和合约词条）。

这是因为在常规关卡中的费用上限就是99，如果超过了这个值就等同于永久无法再部署，因此游戏设置了这个上限。

目前已知的唯一例外是危机合约关卡 切尔诺伯格 13区废墟 ，不仅有费用翻倍的词条，部署费用上限也设成了999，因此能够出现百费以上的干员。

阻挡数

干员能够阻挡的敌人数量。也即通常会同时承受多少名敌人的 近战 攻击。

当干员正在阻挡的 敌人合计阻挡数 等于该值时，之后到来的敌人在经过该干员时将不会被TA阻挡，并直接从TA的位置穿过去。

存在一些阻挡的特例： 有一类敌人的特性为 “无法被阻挡” ，这类敌人一般被称为“幽灵”。比如就叫这个名的 幽灵 和它的变种 工蚁 。 敌人数 和 敌人占用的阻挡数 并不一定是一对一关系。 比如一个人占2个阻挡数的 乌萨斯突击者 、一个人占3个阻挡数的 欺凌者 、甚至一个人占用4个阻挡数的 剧场组装体 等。 这些特例敌人的身上大多都会存在一个 明显的数字 ，用来表示自己占用多少阻挡数（如 欺凌者 肩甲上的数字3， “搭档” 肩部的罗马数字Ⅱ）。

虽然部署在远程位的干员不接敌（尤其是只能部署在远程位的干员），但 远程位干员同样也有阻挡数 ，一般为1，且只在一些特殊设置下（比如“干员布置不受近远程限制”的地图）才会有效果。

一些干员 初始阻挡数即为0 ，典型的代表是特种干员分支“伏击客”。

有些干员会在 某个技能发动期间阻挡数变为0 ，如 桃金娘 、 宴 、 芳汀 等。如果在此时强制增加其阻挡数，他们依然不会阻挡任何敌人。

部分干员可以“同时攻击阻挡的所有敌人”，实际上指的就是可以同时攻击攻击范围内 等同于当前阻挡数 的敌人。

攻击速度

干员的 攻击间隔 大致区间。

速度越快，则攻击间隔越小，单位时间内的攻击次数就更多。注意需与名为“攻速”的属性相区分。

需要注意的是，这里的数据 并不完全反映战场上的真实情况 。 由于各种战场情况引发的属性变动不会显现在这里的干员数据中 ，比如：

天赋： 先锋干员 苇草 在精英一后获得天赋“枯法之血”，可以增加其法术抗性，但是她的基础属性中的法术抗性显示始终为0。

战场环境： 部署于 腐蚀地表 的干员防御力将会减半，部署于 活性源石 上的干员在不断流失生命值的同时攻击力也会有所提高。

关卡条件： 部分关卡的条件会附加初始部署费用翻倍，此时 实际的初始部署费用 = 面板部署费用×倍数 ，并受上面的机制影响。这会产生99费的 伊芙利特 等极高费干员。

如果要确认战场上我方单位的实际数值， 请点按该单位 ，此时画面左侧显示的就是当前时刻的数值，即包含了各种天赋、技能和环境变动的数值。

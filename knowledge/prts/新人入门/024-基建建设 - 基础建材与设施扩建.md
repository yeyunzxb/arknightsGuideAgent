# PRTS · 新人入门 · 基建建设 / 基础建材与设施扩建

龙骨

升级控制中枢的必需材料。通过通关1-1、1-8、3-4、4-7总共可以获得4个。

[图示：基础加固建材] [图示：进阶加固建材] [图示：高级加固建材] 加固建材

升级基建房间必需的原材料，需通过基建加工站合成。

[图示：碳] [图示：碳素] [图示：碳素组] 碳系材料

合成建材类材料的原材料，可从物资筹备-资源保障获取。

无人机

扩展基建设施、加速生产的耗材，通过清理房间提高获取上限。 每6分钟自然回复1架，可通过发电站加速自然回复，也可在控制中枢4级后，使用理智速充，每1理智恢复2架无人机（很亏，一般不推荐这么做）。

使用无人机、龙骨和建材升级控制中枢，可以开辟新的楼层供使用。而新开辟楼层的房间需要消耗一个基础建材清理后才能建造房间，清理房间可以增加无人机的上限。

房间的建造和升级需要无人机和不同等级的建材，可供建造的房间类型也不尽相同。

根据功能和分区，你可以在画面左侧的房间中选择 发电站 / 制造站 / 贸易站 三种生产房间中的一种进行建造。根据需要你可以选择拆除这个生产设施，将会返还给你所消耗的建材（但是无人机是不会返还给你的）。

发电站 能够提供基建所有房间的供电支持，并且加速无人机的充能。进驻干员能够加速无人机的充能速度。

制造站 进驻干员能够生产各种资源类道具。

贸易站 进驻干员能够获取订单，通过销售 赤金 和 源石碎片 换取可观的 龙门币 和 合成玉 。

画面中央的房间则可以建造 宿舍 供工作的干员休息。

画面右侧的房间则具有各种功能性用途，包括 会客室 、 加工站 、 办公室 、 训练室 和 回收站 五个房间。 功能性设施不可降级 。

会客室 能够提升好友上限、解锁新的支援单位栏，并能够与好友互动，获取/交换线索、举办线索交流来获取 信用 。进驻干员可以收集线索。

加工站 能够加工各种材料。进驻干员帮助加工可以概率获得副产物。

办公室 能够增加公开招募的栏位。进驻干员可以获得需求标签的刷新次数。

训练室 能够在后期安排精英2阶段的干员至训练位进行技能专精训练。进驻协助位干员可以缩短专精所需的时间。

于2026年10月09日（ 昨日海 ）版本新增设的 回收站 则能够自动产出养成材料，无需消耗任何原料。进驻干员或投入多余材料（回收站升至3级后）可以加快转化效率。

升级房间能够增强该房间的属性，并为后面升级控制中枢等级作准备。但是除控制中枢和发电站以外，升级房间会增加用电量，因此请在房间升级前确认自己是否有足够多或足够等级的发电站。

除此之外，基建最右侧还有一类特殊的房间 活动室 。它可以使进驻的干员每天额外获得两次提升信赖的机会。但其建设有一定前置门槛，且新手对干员信赖值无需求，不推荐新手投入资源来建造。

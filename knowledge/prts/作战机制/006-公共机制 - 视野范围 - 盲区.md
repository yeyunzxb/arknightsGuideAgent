# PRTS · 作战机制 · 公共机制 / 视野范围 / 盲区

挽歌燃烧殆尽 实装后，以 树丛 / 盾与墙 / 旧日之火 为代表的可以 遮挡我方单位视野 的装置正式登场，其实际效果为令角色获得 盲区 。

将我方单位所在格与场上所有地块的中心及中心周边两个点逐一进行连线（存疑），若任一连线穿过了存在可以 遮挡视野 单位的地块（忽略目的地地块上的此类单位），则该地块会被记为单位的 盲区 。每当场上 树丛 / 盾与墙 / 旧日之火 数量增加/减少，所有单位的盲区都将被立刻更新。

我方单位无法主动选择一个位于自身盲区中的单位（格子判定）作为攻击、能力目标（类似于反向的 迷彩 效果）。

点选单位后，攻击范围内的盲区地块会被标记为灰色

盲区并不是单位的视野范围发生了变化， 单位的“视野范围”不会因为出现盲区而改变 ，故除了挽歌燃烧殆尽本身的机制以外，盲区不会影响任何与视野范围相关的关卡机制 。

丢失的视野范围将变为 灰色 斜条格，在单位部署/在场信息查看时实时变动。

铁钳号·原型机 不属于我方单位，故不会获得盲区机制，但其仍能在挽歌燃烧殆尽中提供我方有效视野。

大部分 直接选择目标 的能力必须在 目标不在盲区中 的情况下（或者说 “能够明确看到目标” ）才能进行。相对的，那些 不直接选择目标 的能力或许 能绕过盲区生效 ，例如：

各类光环效果： 逻各斯 技能“殁亡”的斩杀效果、 铃兰 技能“狐火渺然”的对敌方效果等。

特殊的弹道： 魔王 技能“明日遥远不及”产生的微尘因其独特的碰撞判定，其更近似于 不依赖索敌即可运作 的能力。

强行选择指定单位的能力： 凯尔希 天赋“选择攻击范围内的 Mon3tr(凯尔希的召唤物) 作为治疗目标”、 远牙 技能“同盟支援”可攻击范围外的被阻挡目标。

不进行来源结算的效果：特种-炼金师分支干员技能抛射的炼金单元效果等

注意： 一个技能可能复合多种能力，此时会分别判定各能力的生效状况。 例如 塞雷娅 技能“钙质化”中，减速/法术增伤效果可以生效，但攻击/治疗会因视野受阻无法进行。

对于一些利用其他单位的攻击范围或视野范围的能力，也是依照自己的盲区而非对方的盲区来处理

例如 维什戴尔 被遮挡，认为某格是盲区，但其召唤物 魂灵之影 因位置不同而不认为该格是盲区，就会因为“对一名在维什戴尔攻击范围内的敌人造成法术伤害”而发起攻击。

新约能天使 召唤轰炸时，选取目标由新约能天使进行，因此目标敌人在不在消耗弹药者的盲区里不重要，只要不在新约能天使的盲区这次轰炸就可以正常召唤出；如果消耗弹药者（原本）攻击范围内存在几个“在新约能天使盲区”的单位和一个“不在新约能天使盲区”的单位，你还能看见新约能天使的轰炸全都“随机”召唤在那个不在盲区的单位身上。

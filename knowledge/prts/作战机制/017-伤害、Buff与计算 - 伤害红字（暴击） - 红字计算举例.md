# PRTS · 作战机制 · 伤害、Buff与计算 / 伤害红字（暴击） / 红字计算举例

常规作战： 7-18 中， 老鲤 打出的 109840

作战记录：

老鲤：好消息，109840

计算流程：攻击力 =老鲤面板899×(1+不稳定血浆0.9+爆发剂·榴莲味0.5+ 精力充沛 0.5+协同作战0.36+青色怒火0.14+战术整理·VI0.2)+“潮涌，潮枯”445×(1+0.09+0.14)×1.1=3838.485 爱国者法抗=(面板0.45-灼地0.2- 冻结 0.15)×(1+行军姿态1)×精神融解0.56=0.112 期望伤害 = 攻击力 ×二技能叠满倍率9×(1-爱国者法抗0.112)=34546.365 最终伤害 = 攻击力 ×二技能叠满倍率9×(1-爱国者法抗0.112)×钙质化1.55×支援地雷1.5×灵知第一天赋1.54=109839.61477566 最终伤害 ≥1.5× 期望伤害 ，所以显示红字，最终显示结果为 最终伤害 进位后的109840。 在这一案例中，因为老鲤不具备贯穿能力，故公式可以化简，直接计算钙质化、支援地雷、灵知第一天赋三者提供伤害倍率加成： 伤害倍率 =钙质化1.55×支援地雷1.5×灵知第一天赋1.54=3.5805≥1.5，所以显示红字。

计算流程：{[断罪者攻击力888×(1+活性源石50%+阿榴莲针50%+华法琳血怒90%+诗怀雅天赋36%+近卫小车天赋20%+近卫阿米娅天赋14%)+浊心斯卡蒂攻击力445×(1+浊心斯卡蒂天赋18%+波登可天赋11%+近卫阿米娅天赋14%)×技能倍率110%]×合约加成200%×伤害倍率800%-泥岩巨像防御力600}×慑砂天赋116%×W天赋121%×巫恋天赋[1+(33%×一技能1.8)]=138152.424433

最小单次非零红字伤害： 5-6 中， 刻俄柏 打出的 1

作战记录：

暴击！HP-1

计算流程：目标防御力 =((220-高爆弹头210)×(1-碎甲箭0.35)×(1-聆听0.25)×(1-诅咒娃娃0.5))=2.4375 “攻击力” = 目标防御力 =2.4375 期望伤害 = “攻击力” ×刻俄柏剥壳0.4×(1-目标的法抗0)=0.975。 最终伤害 = “攻击力” ×刻俄柏剥壳0.4×(1-目标的法抗0)×钙质化1.5×(1-目标的法抗0)=1.4625 最终伤害 ≥1.5× 期望伤害 ，所以显示红字，最终显示结果为 期望伤害 =退位后的1。 需要特别说明的是，这个“1”实际为刻俄柏的天赋“剥壳”造成的法术伤害，实际给予的伤害还包括三技能打出的物理伤害，因此被击中的暴鸰·G依旧被击倒。

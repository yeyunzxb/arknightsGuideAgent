# PRTS · 作战机制 · 敌人类单位行动与坐标 / 扩展阅读：波次

在一个关卡中，所有的敌人被划分为许多“波次”（ Wave ），每个波次由许多“兵团”（ Fragment ）组成，兵团再细化成“小队”（ Action ），之后便是一个个单体敌人。

※“兵团”和“小队”仅仅是为了方便理解而采用的称呼。在实际代码中，“兵团”对应的 Fragment 应翻译为“碎片”，而“小队”对应的 Action 应翻译为“动作”。

小队 是最小的波次单位，代表一个或几个行动一致的同种敌人。它们拥有相同的行动设置，可通过参数每隔一段时间才开始行动。 这里的“小队”不一定是敌人，实际上，小队也拥有许多动作指令，此时更接近于其“ Action ”的本意：

TypeID：0；ID：SPAWN；事件名：召唤；备注：将对应的敌人召唤到场上（即“出生”）

TypeID：1；ID：PREVIEW_CURSOR；事件名：显示路径；备注：以红/黄线形式显示绑定的路线

TypeID：2；ID：STORY；事件名：播放浮窗剧情；备注：读取对应的浮窗剧情 并在关卡显示

TypeID：3；ID：TUTORIAL；事件名：？；备注：？

TypeID：4；ID：PLAY_BGM；事件名：播放BGM；备注：暂停当前BGM并播放指定的BGM

TypeID：5；ID：DISPLAY_ENEMY_INFO；事件名：显示敌人信息；备注：在画面右上角弹框显示敌人信息

TypeID：6；ID：ACTIVATE_PREDEFINED；事件名：预部署单位生效(干员)；备注：使预部署但隐藏的单位立刻部署

TypeID：7；ID：PLAY_OPERA；事件名：播放画面特效；备注：执行特殊的画面效果

TypeID：8；ID：TRIGGER_PREDEFINED；事件名：预部署单位生效(装置)；备注：使预部署但隐藏的装置立刻部署

TypeID：9；ID：BATTLE_EVENTS；事件名：战斗事件；备注：执行特定战斗内事件

TypeID：10；ID：WITHDRAW_PREDEFINED；事件名：预部署单位撤回；备注：使在场特定预部署单位立刻撤退

TypeID：11；ID：DIALOG；事件名：播放局内演出剧情；备注：读取对应的局内演出剧情 并在关卡内显示

TypeID：12；ID：SHOW_ALL_HIDDEN_CARDS；事件名：？；备注：？

TypeID：13；ID：EMPTY；事件名：不执行动作；备注：不执行任何动作的占位符，一般用于出兵分支

TypeID：14；ID：E_NUM；事件名：？；备注：执行特定函数动作

兵团 是若干小队的集合，代表一定时间内的出兵。

波次 是若干兵团的集合，代表较长一段时间内的出兵。

# PRTS · 伤害分类 · 按伤害的属性分类

以下分类的本质为伤害本身所具有的属性（部分受到伤害/造成伤害相关的效果会通过匹配伤害的属性来筛选可生效的伤害）。

称呼：物理伤害；基本描述：基本伤害类型，造成伤害时计算防御力。 \(\text{造成的基础物理伤害}=\text{使用属性}-\text{目标防御力}\) ※其中“使用属性”大多数情况下为 自身攻击力 。 ※也存在基于自身其他属性、目标其他属性或固定值作为使用属性的情况（下同）。；备注：/；用例：[图示：迷迭香] [图示：银灰] [图示：陈]

称呼：法术伤害；基本描述：基本伤害类型，造成伤害时计算法术抗性。 \(\text{造成的基础法术伤害}=\text{使用属性}\times\frac{100-\text{目标法术抗性}}{100}\)；备注：/；用例：[图示：艾雅法拉] [图示：安洁莉娜] [图示：慕斯]

称呼：真实伤害；基本描述：基本伤害类型，造成伤害时不计算任何防御属性。 \(\text{造成的基础真实伤害}=\text{使用属性}\)；备注：不指定伤害类型的伤判效果可以对真实伤害生效 也即 真实伤害可以被减免、格挡或闪避 。；用例：[图示：阿米娅] [图示：凯尔希] [图示：耀骑士临光]

称呼：治疗；基本描述：用于治疗行为的基本伤害类型。 \(\text{造成的基础治疗量}=\text{使用属性}\)；备注：无特殊逻辑的治疗行为默认选择生命值不满的单位进行 治疗行为默认受 禁疗 制约。；用例：[图示：华法琳] [图示：赫默] [图示：塞雷娅]

称呼：元素伤害；基本描述：于2023年7月6日更新后加入的新伤害类型。 可以自敌人受到元素爆发影响期间产生（或通过某种方式自行产生），造成伤害时计算元素抗性。 \(\text{造成的基础元素伤害}=\text{使用属性}\times\frac{100-\text{目标元素抗性}}{100}\)；备注：与元素相关的另一个属性 损伤抵抗 也于此同时被添置，作用为减免一定的元素损伤值。；用例：[图示：凛视] [图示：折光]

称呼：无类型伤害；基本描述：类型为 NONE 的伤害；备注：/；用例：——

称呼：普通伤害；基本描述：类型为 NORMAL 的伤害；备注：最常见的攻击类型，站内省略伤害的攻击类型时，默认为此伤害类型。 ※但对于伤害筛选，省略则意味着不判断伤害的攻击类型。；用例：——

称呼：溅射伤害；基本描述：类型为 SPLASH 的伤害；备注：此类攻击型常见于对群的伤害之中，但也有相当一部分群攻只会造成普通伤害而不会造成溅射伤害，因此对于群攻伤害的攻击类型，站内省略时依旧默认为是普通伤害。；用例：——

称呼：持续伤害；基本描述：类型为 BUFF 的伤害；备注：此类攻击型常见于视觉上不依赖攻击，而是通过对目标施加一个持续效果造成的伤害之中。 大多数“毒伤”或DOT伤害即为这一种表现形式 。 ※ 锡人 通过第二天赋为 持续伤害 提供增益的炼金单元可以为上述伤害提供加成。 ※常见表述形式为：（不依赖攻击行为的）每秒造成……/移动1格造成……；用例：[图示：棘刺] [图示：夜魔] [图示：妮芙]

称呼：附加伤害；基本描述：类型为 ADDITION 的伤害；备注：/；用例：[图示：忍冬] [图示：玛恩纳]

称呼：无途径伤害；基本描述：施加途径为 NONE 的伤害；备注：部分Buff会造成无途径伤害。 ※所有限制了“仅对近战途径伤害生效“或”仅对远程途径伤害生效”的效果皆 可对无途径伤害生效 。；用例：——

称呼：近战途径伤害；基本描述：施加途径为 MELEE 的伤害；备注：不产生弹道的攻击为近战途径攻击，攻击本身造成近战途径伤害（攻击附加的Buff可造成其他途径伤害）。 ※“被阻挡时触发的普通攻击（也即阻挡攻击）/未被阻挡时触发的普通攻击”与“近战途径攻击/远程途径攻击”事实上并无明确对应关系，每个单位各不相同。 ※上述攻击途径与敌方图鉴里标注的 攻击方式 无关，后者的本质是单位自身的标签。；用例：——

称呼：远程途径伤害；基本描述：施加途径为 RANGED 的伤害；备注：产生弹道的攻击为远程途径攻击，攻击本身造成远程途径伤害（攻击附加的Buff可造成其他途径伤害）。 ※同上。；用例：——

称呼：全途径伤害；基本描述：施加途径为 ALL 的伤害；备注：极少部分Buff会造成全途径伤害。；用例：[图示：响石]

称呼：非致命伤害；基本描述：拥有 DAMAGE_IS_UNDEADABLE_THIS_TIME 标签的伤害；备注：在应用此类伤害时至多将目标生命值降至1点。 重伤机制通常会使用到非致命伤害来避免因伤害击杀目标；用例：[图示：嵯峨]

称呼：环境伤害；基本描述：拥有 IS_ENVIRONMENT_DAMAGE 标签的伤害；备注：参阅： 自然环境；用例：[图示：特殊地形]

称呼：生命流失；基本描述：拥有 SKIP_MODIFIER_EVENT 标签的伤害；备注：通常为真实伤害使用 ，跳过伤害计算以外的所有步骤与事件，基本确保伤害以原样生效。；用例：[图示：伊芙利特]

称呼：可影响沉睡单位的伤害；基本描述：拥有 DAMAGE_CAN_HURT_SLEEPING_ENTITY 标签的伤害；备注：参阅： 异常效果#可影响沉睡单位的伤害；用例：[图示：瑕光]

称呼：溢出部分可产生屏障的治疗；基本描述：拥有 HEAL_CAN_GENERAL_SHIELD 标签的治疗类型伤害；备注：本次治疗会记录超出干员生命值部分的“溢出治疗量”并触发响应事件，与原文不同，其他溢出治疗量效果也可以依靠此治疗实现。；用例：[图示：摆渡人]

称呼：强制显示红字的伤害（强制暴击伤害）；基本描述：拥有 FORCE_TO_DISPLAY_CRITICAL_NUMBER 标签的伤害；备注：不论是否满足 红字（暴击） 的条件，始终视为暴击、展示红字的伤害。；用例：[图示：蕾缪安]

称呼：斩杀伤害；基本描述：拥有 INSTANT_KILL_LIKE_DAMAGE 标签的伤害；备注：部分效果不会响应斩杀伤害，如 愧悔魂灵圣杯 的光环。；用例：[图示：逻各斯] [图示：傀影与猩红孤钻/长生者宝盒]

称呼：不可改变的伤害；基本描述：拥有 IS_NOT_CHANGEABLE_VALUE_MODIFIER 标签的伤害；备注：在大部分变动伤害的逻辑处理中，始终不受这些逻辑影响的伤害。；用例：[图示：隐德来希]

称呼：撼地者主目标伤害；基本描述：拥有 APPLY_TO_HAMMER_SUBCLASS_MAIN_TARGET 标签的伤害；备注：用于标记一次伤害的对象为撼地者普通攻击的主目标 换言之，只要一次伤害被带上此标签，即使其实际不为撼地者攻击的主目标也会享受与主目标等同的攻击力倍率。；用例：[图示：佩佩]

称呼：撼地者溅射目标伤害；基本描述：拥有 APPLY_TO_HAMMER_SUBCLASS_SPLASH_TARGET 标签的伤害；备注：用于标记一次伤害的对象为撼地者普通攻击的溅射目标 换言之，只要一次伤害被带上此标签，即使其实际不为撼地者攻击的溅射目标也会享受与溅射目标等同的攻击力倍率。；用例：[图示：佩佩]
